# Scanner Cloud, сервер 3.107.5

Дата: 22.11.2026. Safari-закладка остаётся 3.107.

## Причина изменений

Ручная диагностика владельца:
- APINex `free/glm-5.3-flashx`: контрольный запрос успешный, 3.3 с.
- Groq `openai/gpt-oss-20b`: контрольный запрос успешный, 0.7 с.
- OpenRouter `openrouter/free`: модель не вернула JSON, 9.2 с.
- Gemini `gemini-3.8-flash`: запрос превысил лимит 9 с.

Из этого нельзя заключать, что ключи OpenRouter и Gemini недействительны. `openrouter/free` выбирает случайную бесплатную модель, и формат ответа может различаться.

## Исправлено

- Запросы к OpenRouter включают `response_format.type=json_schema`, `strict=true` и обязательные поля `choices`, `answer`, `explanation`, `uncertain`.
- `provider.require_parameters=true` просит маршрутизатор использовать только совместимые с JSON Schema эндпоинты.
- Диагностика OpenRouter показывает идентификатор реально выбранной бесплатной модели при успешном тесте или ошибке разбора.
- Диагностика различает успешно проверенный ключ и последующий тайм-аут генерации (вместо ложного вывода о неисправности ключа).
- Для Groq и APINex формат запроса не менялся, существующая авторизация и токены владельца остаются прежними.

## Проверки

- Синтаксис серверного кода, Safari-клиента и 4 скриптов админ-страницы: 6/6.
- Поддельные ответы провайдеров: OpenRouter получает структурированный `response_format` и `require_parameters`; возвращает реальную модель; Groq и APINex не меняются, все три ответа декодируются.
- Деплой версии `458a7957-ad52-4734-b216-b82b0fa98006` подтверждён на 100% Cloudflare-трафика.
- После деплоя: 4 owner-ключа, 3 действующие owner-сессии, 1 пользователь.

## Важные ограничения

Наличие JSON Schema повышает надёжность формата, но не гарантирует, что свободная модель окажется быстрой или правильной. Если OpenRouter не найдёт совместимую бесплатную модель, он может вернуть ошибку. С Gemini увеличение лимита наугад не делалось: это увеличило бы ожидание, а не исправило причины торможения. Реальные запросы с действующими ключами в этой сессии не выполнены: нужна повторная проверка через админ-панель.
