# Scanner Cloud 3.109 — историческая проверка, честная уверенность и ускорение Gemini

Дата: 22.11.2026. Сервер, админ-панель и Safari-закладка: 3.109. Cloudflare deployment `ccd891a3-5e4e-48e1-a184-9d29eb5eaeaf`, 100% трафика на момент проверки.

## Разбор обнаруженной ошибки
Вопрос из пользовательского скриншота:
«Театр, що відкрив у Парижі Мольєр, має назву:»
A «Блискучий», B «Глобус», C «Яскравий», D «Королівський».

Система 3.108.1 вернула D и назвала это «Сверено» из-за согласия APINex и Groq. Корректная историческая связь: Мольер основал `L'Illustre Théâtre` («Блискучий театр») в 1643 году; позднее его труппа выступала в Пале-Рояль. Отсюда ошибочная подмена отношения «основал» на «позднее выступал».

Источники:
- https://nbuv.gov.ua/node/5916 — Национальная библиотека Украины имени В. И. Вернадского.
- https://uahistory.co/pidruchniki/world-literature-8-class-2021-bogosvyatska-reissue/39.php — учебный текст с названием «Блискучий театр».
- https://www.paris.fr/pages/sur-traces-de-moliere-comedien-et-dramaturge-de-genie-21032 — город Париж, различие театров.

## Исправления
- Поисковая фраза стала короче и предметнее: `мольєр театр` вместо длинной комбинации слов из предложения.
- Увеличена полезная длина извлечений из Wikipedia и добавлен поиск по английской Wikipedia наряду с украинской, русской и Wikidata. Вызовы выполняются параллельно и имеют короткие тайм-ауты.
- Для исторических вопросов с формулировками «відкрив/заснував/основан/открыл/created/founded» справочные материалы используются для дополнительной проверки даже при согласии первых двух моделей.
- Резервная модель получает короткие выдержки из справочников; если она предлагает альтернативу, которая явно фигурирует в найденном материале, итог может измениться, но маркируется как предварительный, не как безусловный факт.
- Ограничены времена дополнительных вызовов: третья текстовая модель максимум ~3 сек, Groq GPT-OSS 120B как углублённый reviewer максимум ~3 сек; это позволяет избежать неоправданно долгого ожидания.
- Gemini 3.8 Flash получает `thinkingConfig.thinkingLevel='LOW'` и `responseMimeType='application/json'` вместо игнорируемого `temperature`. Лимит диагностического запроса Gemini уменьшен до 5,5 сек. Это не гарантия ответа менее чем за 3 сек.
- Убрана вводящая в заблуждение пометка «Сверено» для простого согласия двух AI; UI показывает «Модели согласны».
- Client и server получили версию 3.109, старую Safari-закладку требуется заменить через админ-панель, чтобы получить новую маркировку и сбросить прежний кэш.

## Автоматические проверки
- Синтаксис 8 блоков JavaScript: owner, sources, Safari и 5 скриптов админ-панели.
- Синтетический регрессионный случай Мольера: первоначальное согласие Groq+APINex за D, дополнительный ответ по справке за A, итог A с явно обозначенной неопределённостью.
- Синтетический запрос Gemini проверен на JSON MIME, LOW thinking и отсутствие deprecated temperature.
- Отдельно пройдены случаи: согласие двух моделей без источников; Wikimedia недоступна; отказ всех API.
- После деплоя: 4 ключа владельца, 3 активных личных сессии, 1 аккаунт участника.
- Обновлённые 6 исходных файлов сохранены в GitHub.

## Ограничения и риски
- Изменения проверены на поддельных API-ответах и официальных внешних источниках. **Реальные production вызовы через все ключи и новая точность на 24 вопросах не проверялись**.
- Поиск Wikipedia может быть недоступен из production Worker; его доступность проверяется вручную кнопкой «Проверить Wikipedia и Wikidata» в админ-панели.
- Автоматическое сопоставление слова из выдержки с вариантом может дать ложную зацепку, поэтому источник используется для перепроверки и предварительного вывода, не для безусловного присвоения «верно».
- Согласие нескольких AI не доказывает правильность; глобальную оценку «8/10 по точности» до повторного теста давать нельзя.
- Старый Worker 3.103 не изменён. Ключи не переизданы.

## Как проверять
Создать личную закладку 3.109; убедиться, что статус сервера 3.109; проверить доступ к Wikipedia/Wikidata в админ-панели. На тренировочных вопросах с известным ключом ответов оценивать отдельно читаемость вопроса, выбранную модель, наличие выдержки, смысл исторических глаголов, затраченное время и верность ответа.
