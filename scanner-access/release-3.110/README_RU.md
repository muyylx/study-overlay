# Scanner Access 3.110 (подготовлено, в Cloudflare НЕ выложено)

Основа: код, который сейчас работает в Cloudflare (Scanner Access 3.109). Секретов и ключей в файлах нет.

## Что изменено

**Скорость (путь участников, `providers.js`)**
- Быстрая и сильная модели запускаются одновременно. Первая рабочая не ждёт зависшую вторую: максимум 1,5–3 с ожидания второй, потом ответ.
- Общий лимит времени 8 с (с картинками 17 с) вместо суммы таймаутов до 12,5 + 12,5 с (с картинками до ~40 с).
- Один повтор запроса при временной ошибке 5xx.
- Если все модели упали, делается упрощённый запрос «только буква». Пустой экран остаётся только когда API реально недоступен.

**Точность**
- Модель сначала разбирает варианты (поле `reasoning`) и только потом выбирает ответ. Раньше ответ шёл первым.
- Усилен промпт: отрицания, даты, имена, путаница исторических событий.
- Устойчивый разбор ответа: JSON в блоке кода, ответ текстом «Ответ: C», название варианта вместо буквы.
- Арбитр запускается только при споре моделей или если модель не уверена. Википедия RU/UK/EN даётся арбитру как подсказка, не как доказательство. Запрос строится из имён, дат и длинных слов.
- Статусы честные: «Модели согласны (это не доказательство факта)», «Ответ одной модели», «Спор решён арбитром (предположение)». Добавлено поле `confidence` (high / medium / low).

**Картинки**
- Картинки вариантов подписываются буквой («Вариант A»), картинка вопроса отдельно. Раньше они шли в порядке на странице без привязки к буквам.
- Размер до 1280 px, качество выше, лимит до 8 картинок.
- Если Safari не отдаёт картинку из-за CORS, вместо потери передаётся https-ссылка на неё, модель загружает её сама.
- Модели читают картинку в два шага: сначала переписывают видимый текст и числа (`reading`), потом решают.
- Параллельно с vision идёт текстовый запрос как страховка. Если картинка не прочитана, это прямо указано в ответе.

**Личная версия (`owner.js`, `owner-client.js`)**: тот же приём «сначала рассуждение», таймаут чтения картинки 3,6 с. Логика нескольких провайдеров не менялась.

**Версии и надписи**: везде 3.110. Слово «Cloud» убрано из видимых надписей. Участники на 3.102–3.109 получат уведомление об обновлении (не блокирующее). Чтобы получить новую обработку картинок, участник должен заново поставить закладку.

## Что проверено

- 11 сценариев оркестрации на имитации API (быстрое согласие, зависшая модель, спор, все модели упали, не-JSON, ошибка 503, картинки, открытый вопрос, отклонение небезопасных ссылок): все прошли.
- Клиент в настоящем Chromium на тестовой странице: подписи вариантов, уменьшение 3000 px до 1280 px, запасной вариант со ссылкой.

## Что НЕ проверено

- Работа с настоящими API APINex, Groq и др.: в среде проверки нет интернета.
- Работа на iPhone в Safari и на реальных сайтах (Naurok, Kahoot).
- **Точность на реальных вопросах**: измерений ещё нет, обещать улучшение числами нельзя. Нужен тестовый набор из реальных вопросов.

## Откат

Не удаляй 3.109. В Cloudflare у Worker есть история развёртываний, предыдущую версию можно вернуть.
