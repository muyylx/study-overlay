# Scanner Access 3.113 · участники

Дата: 2026-11-23

- Исправлена высота пользовательского iframe: больше не используется ограничение `.box { max-height:49vh }` внутри малой рамки, вместо этого реальная высота содержимого передаётся в bookmarklet, длинные OCR-результаты прокручиваются.
- OCR: выбранный файл открывается через `createImageBitmap`, с резервным `FileReader`; добавлена поддержка HEIC/HEIF в Safari, итоговый файл передаётся как JPEG.
- После сбоя клиент показывает этап: подготовка изображения или вызов OCR. Сервер различает сбои ключа, модели Vision и лимита API и умеет принять обычную текстовую транскрипцию, если JSON отсутствует.
- Кнопка «Разобрать» продолжает читать HTML-страницу и не связывается с загруженным скриншотом. OCR остаётся только распознаванием текста без заполнения учебных полей.
- Текущая версия публичной Safari-закладки: 3.113, её нужно скопировать с `scanner-cloud/update.html` вместо прежней 3.112. Личная закладка владельца остаётся 3.111.
- Приватные ключи, D1 и пользовательские сессии не пересоздавались.

Проверено: JavaScript-синтаксис, Cloudflare deployment 100%, четыре bindings; HTTP-проверка public workers.dev из используемого инструмента недоступна, поэтому фактическое распознавание на iPhone не подтверждено.
