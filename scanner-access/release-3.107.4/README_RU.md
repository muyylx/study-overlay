# Scanner Cloud 3.107.4 — исправления после теста 12/24

Дата: 22 ноября 2026. Сервер: **3.107.4**. Личный Safari-клиент: **3.107** (без необходимости переустановки после этого серверного изменения).

## Подтверждённая ошибка
Groq GPT-OSS 20B / 120B не поддерживают поле `reasoning_format`. В ранее развернутой серверной версии `solveOne` выставляло `reasoning_format: "hidden"` для GPT-OSS, что могло приводить к HTTP 400. Исправлено на `include_reasoning: false` при `response_format: {type:"json_object"}`.

Источник: https://console.groq.com/docs/reasoning (раздел GPT-OSS Models).

## Проверки и задержки
- Две основные текстовые модели запускаются параллельно, но ожидание второго ответа увеличено до разумного предела, чтобы не терять возможность сверки при небольшой задержке.
- Если две модели не согласны, сначала вызывается третий провайдер; при необходимости — Groq GPT-OSS 120B для дополнительного анализа.
- Два ответа разных моделей Groq считаются ответами **одного провайдера**, а не двумя независимыми подтверждениями.
- Когда уже есть согласие двух разных провайдеров, дополнительная проверка большой моделью пропускается, чтобы не тратить время и токены.
- Общий программный бюджет обработки текстового вопроса уменьшен до **10 секунд**, необходимого изображения — до **16 секунд**. Это не жёсткая гарантия клиентского времени, поскольку сеть и загрузка страницы отдельно.
- При разногласии хотя бы один полученный вариант может быть показан как **предположение**, с пометкой «правильность не подтверждена», вместо пустого вывода.
- Если все провайдеры недоступны или необходимая иллюстрация не передана, корректный ответ вычислить невозможно. Случайный вариант автоматически не подставляется.

## Автоматизированные синтетические испытания
- Совпадение двух независимых провайдеров → подтверждённый итог.
- Разногласие без третьего провайдера → вариант с пометкой предположения.
- Согласие третьего независимого провайдера → подтверждённый результат без лишней четвёртой проверки.
- Несогласие и дополнительная модель Groq → не трактуется как второй независимый провайдер.
- Отказ одного провайдера → предварительный вариант другого.
- Отказ всех моделей → безопасная ошибка, не случайная буква.
- Все шесть JavaScript-модулей / фрагментов прошли компиляцию без синтаксических ошибок.
