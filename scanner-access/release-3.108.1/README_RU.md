# Scanner Cloud 3.108.1 — Wikimedia fact-checking and source diagnostics

Релиз: 2026-11-22. Worker `scanner-access-a43f105622`, deployment `1d82baf0-f110-4cfc-9445-e1bf41829273` на 100% трафика.

## Основание
Результат пользователя на реальном наборе учебных вопросов — **11 из 24**. Контрольный тест `2+2` для API-ключа не измеряет предметную точность: успешно пройденный ключ может ошибаться в истории, литературе, географии и т. д.

## Что сделано
1. Новый модуль `sources.js`: Wikipedia (uk), Wikipedia (ru), Wikidata. Только официальный MediaWiki Action API и `wbsearchentities`, GET, с корректным User-Agent.
2. Поиск по тематическим словам, а не полная пересылка задания в Wikimedia. Короткие выдержки и безопасные URL; ограничение количества результатов. Для вычислительных/визуальных задач пропускается.
3. Три независимых поисковых вызова параллельно с коротким тайм-аутом (1.45–1.7 с), временный in-memory кэш на 3 минуты, лимит 48 записей.
4. Основные Groq и APINex начинают работу параллельно с источниками. При отсутствии расхождений ожидание незавершённого поиска не дольше 180 мс. При разногласии или потенциальном противоречии из доступных материалов резервная модель получает справочные выдержки (как недоверенные данные, не инструкции).
5. Если внешние сервисы недоступны, основной AI-запрос продолжает работу. Источники не считаются доказательством правильности: если найдена возможная несовместимость, ответ помечается как сомнительный.
6. Результат с реально использованными материалами включает названия и URL источников.
7. В админ-панели появилась кнопка **«Проверить Wikipedia и Wikidata»**. Она обращается из production Worker к обоим сайтам и показывает HTTP-статус, задержку и количество найденных справочных результатов. Маршрут защищён текущей админ-авторизацией и требованием специального заголовка.

## Проверки
- 8/8 синтаксических проверок (owner, sources, Safari и 5 админ-скриптов).
- Исторический вопрос о Мольере запускает поиск; математический пример не запускает.
- В имитации API дополнительная модель получает реальные выдержки Wikipedia (uk/ru) и Wikidata.
- При неисправном источнике AI-ответ продолжает формироваться.
- При зависшем внешнем поиске дополнительная задержка успешного согласованного ответа ограничена примерно 180 мс в синтетическом тесте.
- После развёртывания: 4 ключа, 3 активные личные сессии и 1 пользователь.
- Версии: сервер 3.108.1, клиент Safari 3.107 (совместим, не требуется переустановка).

## Ограничения и честная приёмка
- Тестовая инструментальная среда возвращает `403 Forbidden: requests to uk.wikipedia.org are not allowed`. Это **не** подтверждает работу внешних запросов из production Cloudflare Worker. Для проверки используется кнопка в админ-панели.
- Ни один новый реальный тест на 24 вопросах с известными правильными ответами пока не проведён. Утверждение об улучшении точности было бы преждевременным.
- Wikipedia/Wikidata могут отсутствовать, иметь неполные статьи или неподходящие совпадения; совпадение AI-моделей не доказывает истинность.
- Старый Worker 3.103 не отключён. Существующие API-ключи и сессии сохранены.
