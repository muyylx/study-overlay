# Scanner Cloud 3.107 / Scanner Access backend 3.107.1

Дата: 22 ноября 2026. **Клиент Safari: 3.107, сервер: 3.107.1.**

## Причина ухудшения по сравнению с 3.103

В личной ветке 3.104–3.106.1 запросы к моделям стали последовательными, исчезла полноценная сверка выводов, а любое найденное на странице изображение приводило к выбору визуальной модели. В старом Worker 3.103 для обычных вопросов параллельно запускались два провайдера; отдельно определялась необходимость анализа фотографии. При отказе Gemini 503 или ошибке JSON новая цепочка могла долго перебирать модели и завершаться без результата.

## Изменения 3.107

- Восстановлена обработка **двумя провайдерами параллельно**. Для текста приоритет: Groq и APINex; остальные используются как резерв.
- Два совпавших результата помечаются как сверенные. Несогласованные выводы без большинства не выдаются за проверенные. При необходимости подключается третий провайдер.
- Картинка, не необходимая для понимания вопроса, **не кодируется Safari и не передаётся модели**. Это снижает задержку на текстовых заданиях с декоративной иллюстрацией.
- Сервер ограничивает общую обработку примерно 12 секундами для текста и 18 секундами для необходимых изображений; отдельные запросы также ограничены.
- Ошибки провайдеров возвращаются с безопасной диагностикой (провайдер, модель, длительность, текст ошибки без ключей).
- Улучшены разбор JSON и корректно обозначенная неопределённость. Ответ из простого текста принимается лишь как предварительный; не выдаётся за проверенный.
- В Safari выводятся объяснение и статус проверки; неуверенные ответы не сохраняются в кэше.
- Сохранены схемы и ключи пользователей, 30-дневные личные сессии и отдельная авторизация участников.

## Дополнение сервера 3.107.1

- Если вопрос требует изображения, но Safari не передал его, возвращается статус «Недостаточно данных», а не ответ текстовой модели наугад.
- Подписи к изображениям сохраняются и передаются мультимодальным API вместе с изображениями.
- Safari 3.107 совместим с сервером 3.107.1, переустановка из-за серверного дополнения не требуется.

## Синтетические проверки

- JavaScript исходники и скрипты админ-панели компилируются без синтаксических ошибок.
- Текстовый вопрос с декоративной фотографией не попадает на визуальную ветку.
- Визуальный вопрос с фотографией требует анализа изображения.
- Отсутствие нужного изображения не вызывает необоснованного выбора.
- Два одинаковых ответа в параллельном тесте дают подтверждённый вывод.
- Два противоположных ответа дают статус разногласия, а не произвольную букву.
- Провалы обоих API дают структурированную диагностику.
- Ответ модели без JSON не маркируется как проверенный.

## Развёртывание

Cloudflare Worker: `scanner-access-a43f105622`. Финальная версия `4bea390b-0a1a-4978-9585-b1e40bc91be0` обслуживает 100% трафика. После развёртывания проверено: 4 сохранённых owner-ключа, 2 действующие owner-сессии, 1 участник.

**Ограничения:** публичное HTTP-обращение к Worker блокируется средой инструментов, поэтому вызовы настоящих ключей и поведение Safari на iPhone в этой сессии не подтверждены. Gemini 503 остаётся внешней ошибкой; переключение маршрутов не «лечит» провайдера. Совпадение двух моделей не гарантирует фактической истинности. Старый Worker 3.103 не удалён.

## Ручная приёмка

1. Обновить админ-панель, убедиться в версии сервера 3.107.1.
2. Нажать «Проверить все ключи».
3. Создать новую личную закладку **3.107** и заменить старый адрес Safari.
4. Проверить учебный текстовый пример с декоративной картинкой: фото не должно вынуждать Gemini-ветку.
5. Проверить отдельно задание, которое действительно требует изображения, и обработку отсутствующего рисунка.
6. Убедиться, что у участников сохранились доступ и собственные ключи.

Этот релиз не следует оценивать на 8/10 по надёжности без испытаний с реальными запросами и измерения скорости/точности на выборке.
