# Scanner Access 3.120 R2 Beta
Локальная сборка для самостоятельной учебной практики. Не замена production Worker. Owner preview — диагностический режим, не авторизация администратора. Не публиковать локальный API в интернет.
Node.js 20+. PowerShell: `$env:MOCK='1'`, затем `node server.mjs`. Откройте http://127.0.0.1:8788/ на этом компьютере. Для реального ИИ отключите MOCK и настройте AI_URL (HTTPS Chat Completions endpoint), AI_KEY, AI_TEXT_MODEL и AI_VISION_MODEL согласно документации провайдера. Не помещайте ключи в код или репозиторий. Для изображения нужна поддержка image_url data URL. Демо не выдаёт ответ модели. Поддерживаемые языки RU/UK/EN. Владелец видит диагностику времени и модели. 
Проверки: `node test.mjs`. Реальный API и Safari не проверены. Для переноса в Cloudflare нужны отдельный адаптер Workers, авторизация и проверка квот. Production 3.119 и личный доступ не меняются.
