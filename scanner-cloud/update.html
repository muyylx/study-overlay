Scanner Cloud • личная Safari-закладка

Перенос токена из старой закладки отключён. Новую личную закладку выпускает только приватная панель владельца. Старые рабочие закладки не отключены.

  1. Открой свою приватную админ-панель Scanner Access по сохранённому личному адресу.
  2. Войди с паролем администратора.
  3. Открой раздел личной Safari-закладки и нажми «Создать личную закладку».
  4. Скопируй выданный JavaScript в адрес своей закладки Safari.
Код активации участника и пароль администратора не нужно вставлять на эту публичную страницу. Личные токены не передаются через сайт GitHub Pages.

Если потеряна сессия участника, используй в Scanner Access кнопку «Восстановить вход без нового кода», а не одноразовое приглашение.
