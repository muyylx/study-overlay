Обновление Scanner Cloud

Для личной панели Scanner Cloud 3.100. Это не установка Scanner Access для участников, поэтому новый код не попросит код активации.

Как обновить закладку в Safari

  1. Открой «Закладки» и найди работающую закладку Scanner Cloud.
  2. Нажми «Изменить» и скопируй весь адрес, начинающийся с javascript:.
  3. Вставь его в поле ниже. Страница перенесёт частный токен в новую версию только на твоём устройстве.
  4. Нажми «Подготовить код», затем «Копировать». Замени адрес той же закладки на получившийся код.

Токен не отправляется на сервер и не сохраняется в аккаунт. Запрос к GitHub Pages получает только публичный шаблон нового сканера. Не отправляй никому старый или новый код с частным токеном.

Код Scanner Cloud 3.101 готов

В новой версии появится проверка обновлений и кнопка «Код новой версии» при выходе следующего релиза.

Safari ограничил автоматическое копирование. Выдели весь код в поле ниже и выбери «Копировать».

Сохрани новый адрес в закладке. Личный токен включён в код, поэтому никому его не пересылай.
