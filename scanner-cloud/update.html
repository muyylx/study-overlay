Scanner Cloud 3.101

Обновление твоего сканера. Без регистрации, нового аккаунта и ввода кода активации.

Получить новый код

  1. В Safari открой закладки, найди Scanner Cloud 3.100 и нажми «Изменить».
  2. Скопируй адрес закладки, начинающийся с javascript:.
  3. Вернись сюда и нажми кнопку ниже. При запросе Safari разреши вставку из буфера.

Теперь замени адрес своей закладки этим кодом. Старую закладку можно сохранить как резервную.

Сайт читает скопированный код только после нажатия кнопки. Личный токен вставляется в новый код прямо на устройстве и никуда не отправляется. GitHub отдаёт лишь публичный шаблон. Код с токеном никому не пересылай.
