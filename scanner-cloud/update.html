Scanner Cloud 3.103

Обновление твоего сканера. Без регистрации, нового аккаунта и ввода кода активации.

Получить новый код

  1. В Safari скопируй адрес своей старой рабочей закладки Scanner Cloud (начинается с javascript:).
  2. Вставь его в поле ниже или используй кнопку «Вставить из буфера».
  3. Нажми «Подготовить код», затем «Выделить весь код» или «Скопировать код».

Проверка отправляет токен только твоему Cloudflare Worker. Модели ИИ не вызываются, токены на них не расходуются. Может учитываться обычный лимит запросов Worker.

Замени адрес Safari-закладки готовым кодом. Старую закладку лучше сохранить как резервную.

Старый код и новый код обрабатываются локально в Safari. При подготовке код и токен никуда не отправляются. Только при отдельном нажатии «Проверить приватный токен» токен передаётся твоему Cloudflare Worker по HTTPS, без обращения к ИИ. Код с токеном никому не пересылай.
