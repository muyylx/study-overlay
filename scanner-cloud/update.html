Document Reader 3.118 · OCR-закладка

Новая плавающая панель для чтения выбранных изображений. Локальный OCR, без входа и API-ключа. Не решает тесты и не считывает содержимое открытой страницы автоматически.

Код готов. Вставь его в адрес отдельной закладки Safari. При запуске появится окно с кнопкой закрытия.

Предварительная версия: некоторые сайты блокируют iframe. Если панель не загрузилась, открой OCR отдельно. На реальном iPhone пока не проверено.

Прежняя закладка 3.117

Это обычная пользовательская закладка 3.117. Она открывает панель Scanner Access на странице. Для входа нужен код активации, выданный администратором.

Загружаю актуальный JavaScript…

Новое в версии 3.117: положение панели подстраивается под экран iPhone, распознанный текст можно скопировать, ошибки OCR отображаются подробнее, а сервер проверяет доступность базы. Установи новый JavaScript вместо старого.

Что нового в 3.117: «📷 Лист на странице» пытается прочитать учебное изображение напрямую, а «📄 Считать текст с фото» открывает скриншот из галереи. Если PNG помещается в лимит, текст не ухудшается JPEG-сжатием. Повторное чтение точно того же снимка использует результат в памяти до закрытия панели.

3.117: улучшена обработка выбранных фотографий и проверка формата OCR. Оборванный текст и некорректный ответ модели теперь отмечаются как ошибки, а не как успешное распознавание. Точность распознанного текста необходимо проверять по оригиналу.

3.117: версия установленного JavaScript теперь отображается внизу панели. Обработка изображений со страницы переведена на асинхронное кодирование; поздние ответы от предыдущих запросов OCR игнорируются. Целевое время 5–8 секунд не является гарантией скорости внешней модели.

Document Reader 3.118 (предварительная версия): Открыть отдельный локальный OCR для фотографий документов. Без API-ключа и регистрации. Действующая основная Safari-закладка остаётся 3.117; новый отдельный OCR доступен в закладке 3.118 выше. Не используйте её на недоверенных сайтах: прежний механизм входа может сохранять токен в хранилище посещаемого сайта.

Как установить на iPhone

  1. Нажми «Скопировать JavaScript».
  2. В Safari сохрани любую страницу в закладки через «Поделиться» → «Добавить закладку».
  3. Открой список закладок → «Изменить» → выбери созданную закладку.
  4. Полностью замени её адрес скопированным JavaScript и сохрани.
  5. Открой нужную страницу и запусти закладку. При первом входе введи свой код от администратора в появившейся панели.

Для чтения листов-картинок открой панель и нажми «📄 Считать текст с фото». Если чтение не удалось, панель теперь покажет, произошла ли ошибка файла или OCR-сервиса. Кнопка «Разобрать» работает с текущей страницей, а не загруженным скриншотом. Это распознавание текста, а не автоматическое заполнение заданий.

После обновления 3.117 панель подстраивается по высоте без белой области. Старую Safari-закладку нужно заменить новым кодом один раз.

Если Safari не разрешает автоматическое копирование, нажми «Выделить код» и скопируй его через меню iPhone.

Для владельца: личный JavaScript создаётся отдельно в приватной админ-панели. Здесь нельзя получить токен владельца, и перенос старых токенов не требуется.

После активации вход обычно сохраняется. Если Safari потерял сессию, в панели доступна функция восстановления входа без нового кода при наличии действующей сессии.

Источник кода: публичный Worker Scanner Access. Открыть исходный JavaScript отдельно.
