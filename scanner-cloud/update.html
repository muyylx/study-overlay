Публичный код не содержит твоего токена. Для работы личной панели вставь адрес старой рабочей закладки ниже и нажми «Перенести токен». API-ключи моделей и доступы участников не меняются.

При подготовке токен обрабатывается локально. Проверка токена отправляет его только твоему Cloudflare Worker без обращения к моделям ИИ. Не пересылай личный код другим.
