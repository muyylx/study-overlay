# Scanner Cloud 3.101 · обновление личной Safari-закладки

**Это личный Scanner Cloud, а не Scanner Access для участников.** Панель Scanner Access просит отдельный код активации и не заменяет личную панель владельца.

- [Обновить закладку с 3.100 на 3.101](./update.html): страница переносит существующий личный токен **локально в браузере** и не отправляет его на сервер. Измените адрес старой закладки Safari на подготовленный код.
- [Публичный исходник 3.101](./client-v3.101.js): содержит только заглушку `__SCANNER_PRIVATE_TOKEN__`; не публикуйте свою рабочую закладку с настоящим токеном.
- Новая панель обращается к серверному `/health` при запуске и раз в пять минут. Когда сервер укажет более новую версию, появляется предупреждение и кнопка **«Код новой версии»**. Если сервер недоступен, проверка версии не мешает обычной работе.
- **Старая закладка 3.100 не могла предупреждать об обновлениях до установки 3.101**, потому что в её коде проверки версии не было. Один ручной перенос неизбежен.
- Серверный алгоритм остаётся Scanner Cloud 3.100; добавлены только поля `latestClientVersion`, `minimumClientVersion`, `installUrl` в `/health`. Секреты и вызовы моделей не изменялись.
- Сборка кода и локальный сценарий переноса проверены на синтаксис и тестовом токене, но реальный Safari на iPhone пока не проверен.

# Scanner Cloud 3.100 · быстрый режим Kahoot

## Что обновлено

- **Личный Scanner Cloud**: версия `v3.100` под плавающей панелью. Требуется заменить код старой Safari-закладки новым личным файлом из чата.
- Kahoot: распознавание вариантов по цветам и фигурам, включая вопросы с 2 или 4 вариантами. UI отображает только краткий результат: `▲ (красный)`, `◆ (синий)`, `● (жёлтый)` или `■ (зелёный)`. Панель можно свернуть.
- Kahoot: сканирование по содержанию вопроса без привязки к текущей секунде таймера; авто проверяет изменения чаще, но не отправляет один вопрос повторно.
- Сервер: `/solve?quick=1` запускает быстрые модели параллельно и отдаёт первый пригодный результат, не ожидая длинной проверки Википедии. Если второй ответ приходит почти одновременно, модельные ответы сравниваются. Для вопросов, явно опирающихся на картинку, текстовая модель не имеет приоритета.
- Обычный разбор НаУрок продолжает использовать прежнюю глубокую логику с материалами Википедии и дополнительными проверками.
- Частный токен остаётся только в личной закладке; **этот публичный исходник с `__SCANNER_PRIVATE_TOKEN__` не запускается без приватной настройки**.

## Проверки и ограничения

- Chromium: 4 теста (считывание цветных вариантов, формат ответа, защита от повторного запроса при изменении таймера, реакция на новый вопрос и сворачивание).
- Worker с имитацией API: 3 теста (быстрый текстовый ответ, приоритет Vision для картинки, быстрый текстовый путь для необязательного изображения).
- Локальные замеры со специально заданными задержками **не являются фактическим временем ответа настоящих ИИ**. Нельзя гарантировать ответ за 10 секунд: сеть, лимиты и задержки провайдеров могут помешать.
- При одном ответе отображается отметка «Предварительно». При разногласиях нет гарантии правильного выбора.
- Реальное поведение в Safari на iPhone и в Kahoot ещё не подтверждено.
- Ни один скрипт не нажимает ответы и не отправляет тест.

Исходники: [client-v3.100.js](./client-v3.100.js), [worker-v3.100.js](./worker-v3.100.js). Автотесты: [браузер](./tests/test_v3_100_client.py), [сервер](./tests/test_v3_100_worker.mjs).

### Важные ограничения

GitHub содержит **только публичный исходный код**, личный отзывной токен в нём заменён на `__SCANNER_PRIVATE_TOKEN__`. Личную закладку с токеном нельзя публиковать в репозитории. Ключи моделей остаются в секретах Cloudflare и базе с шифрованием.

Это образовательная панель с разбором и объяснением; она не нажимает варианты и не отправляет тест. Совпадение ответов моделей не является доказательством. Качество распознавания картинок зависит от фактической поддержки Vision выбранным провайдером и разрешений браузера. Реальные API-запросы и Safari на iPhone в этом обновлении не проверены.

# Архив изменений v6.1
Компактная Safari-панель для разбора учебных вопросов. Это публичный **исходник без секретов**; здесь намеренно используется `__SCANNER_PRIVATE_TOKEN__`.

## Что изменилось
- Кнопка **−** сворачивает всю панель до переносимого кружка **⌕**. Нажатие на кружок снова раскрывает её.
- Автоматическое сканирование ждёт **два последовательных стабильных снимка** вопроса, прежде чем обращаться к Worker.
- Ручной запуск и авто используют один отпечаток: **один запрос на один неизменившийся вопрос** в авторежиме, даже если запрос завершился ошибкой.
- В отпечаток входят текст, варианты и стабильные адреса/подписи изображений; **номер вопроса исключён**, поэтому его позднее обновление не вызывает повторную отправку.\n- Выделение текста пользователем не влияет на автоматический режим.\n- После прихода ответа панель перепроверяет текущий вопрос, если страница меняется, вместо немедленного ложного предупреждения о новом задании.
- Повторный ручной разбор возвращается из кэша, если есть готовый результат. После ошибки ручная кнопка позволяет повторить запрос.
- Клиент проверяет, что сервер не прислал несуществующие буквы вариантов или несколько ответов на вопрос с одним вариантом.
- Если вопрос изменился во время выполнения запроса, устаревший ответ не показывается поверх следующего.
- Ссылки Wikipedia/Wikidata и отметка расхождения моделей остаются доступными.

## Лимиты\nCloudflare Worker: **40 запросов за 60 секунд на IP** (ранее 8). Это защитный лимит сервера; квоты AI-провайдеров действуют отдельно. Не отключайте защиту для публично доступного API.\n\n## Проверки
В локальном синтетическом браузерном тесте: 2 разных вопроса вызвали ровно 2 запроса; ручной запуск с последующим включением «авто» вызвал 1 запрос; выбор варианта после сворачивания не создал нового запроса; ошибка API не привела к циклическому авторетраю, но ручной повтор сохранился. Для v6.1 выполнено дополнительно 5 локальных проверок в Chromium: изменение только номера, ручной+авто, реальная смена текста, ошибка 429 без циклического повтора, загрузка изображения без дублирования. 5/5 прошли. Это не тест реального Safari или качества ИИ.

## Безопасность
**Не храните API-ключи и приватный токен доступа к Worker в этом публичном репозитории.** Ключи провайдеров находятся только в Cloudflare Workers Secrets. Для личной установки используйте приватный bookmarklet из диалога, не содержимое этого публичного файла напрямую. Bookmarklet сам по себе содержит отзывной токен доступа, поэтому распространять его нельзя.

Панель не нажимает варианты и не отправляет школьный тест автоматически. Совпадение ответов моделей и ссылки Wikipedia не гарантируют фактическую правильность.
