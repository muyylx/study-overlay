# Scanner Cloud v6

Компактная Safari-панель для разбора учебных вопросов. Это публичный **исходник без секретов**; здесь намеренно используется `__SCANNER_PRIVATE_TOKEN__`.

## Что изменилось
- Кнопка **−** сворачивает всю панель до переносимого кружка **⌕**. Нажатие на кружок снова раскрывает её.
- Автоматическое сканирование ждёт **два последовательных стабильных снимка** вопроса, прежде чем обращаться к Worker.
- Ручной запуск и авто используют один отпечаток: **один запрос на один неизменившийся вопрос** в авторежиме, даже если запрос завершился ошибкой.
- В отпечаток входят номер вопроса, текст, варианты и ссылки/подписи изображений. Переключение вопроса обрабатывается отдельно.
- Повторный ручной разбор возвращается из кэша, если есть готовый результат. После ошибки ручная кнопка позволяет повторить запрос.
- Клиент проверяет, что сервер не прислал несуществующие буквы вариантов или несколько ответов на вопрос с одним вариантом.
- Если вопрос изменился во время выполнения запроса, устаревший ответ не показывается поверх следующего.
- Ссылки Wikipedia/Wikidata и отметка расхождения моделей остаются доступными.

## Проверки
В локальном синтетическом браузерном тесте: 2 разных вопроса вызвали ровно 2 запроса; ручной запуск с последующим включением «авто» вызвал 1 запрос; выбор варианта после сворачивания не создал нового запроса; ошибка API не привела к циклическому авторетраю, но ручной повтор сохранился. Это не тест реального Safari или качества ИИ.

## Безопасность
**Не храните API-ключи и приватный токен доступа к Worker в этом публичном репозитории.** Ключи провайдеров находятся только в Cloudflare Workers Secrets. Для личной установки используйте приватный bookmarklet из диалога, не содержимое этого публичного файла напрямую. Bookmarklet сам по себе содержит отзывной токен доступа, поэтому распространять его нельзя.

Панель не нажимает варианты и не отправляет школьный тест автоматически. Совпадение ответов моделей и ссылки Wikipedia не гарантируют фактическую правильность.
