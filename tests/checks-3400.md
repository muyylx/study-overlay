# Проверка версии 3.4

Публичную страницу НаУрок «Тест з Української мови» открыли в Chrome. Проверили, что на ней четыре отдельных карточки. У каждой свой заголовок и список ответов. На основе увиденных элементов составили тест с двумя соседними карточками. Адрес страницы — https://naurok.com.ua/test/test-z-ukra-nsko-movi-3506558.html.

| Проверка | Где выполнялась | Итог |
|---|---|---|
| НаУрок, Google Forms, Moodle, экран с одним вопросом, обычный fieldset, дробь в MathML, неизвестное изображение и выбор второй карточки | DOM в Node.js, включая запуск кода панели. Разметка остальных платформ модельная | 14/14 |
| Ранее добавленные функции расчёта, перевода единиц, истории, перепроверки и контекста | Локальные тесты клиентского кода | 117/117 |
| Учётная запись, одноразовые приглашения, лимиты, бонусы, поддержка, прекращение приёма идей, ошибки ИИ | Копия развёрнутого Worker, SQLite в памяти, подставные ответы моделей | 25/25 |
| Пять изображений с печатным текстом: умножение, химическая формула, английский, скорость и украинская грамматика | Запросы к действующей модели распознавания и ответа в Workers AI | 5/5 |

Для DOM-тестов нужен Node.js и пакет linkedom. Команда из корня проекта: `node --test tests/reader-3400.mjs`. Для автономного ESM-файла linkedom путь задаётся переменной LINKEDOM_MODULE.

В замерах изображений использовались чистые тестовые PNG. Загрузку с камеры, отражения, рукопись, Safari на физическом iPhone, сессии по PIN и тесты в закрытых школьных кабинетах этот прогон не проверял. Результаты не оценивают точность по всем темам.

Обновление панели загружается с сайта. Чтение страницы выполняет код, сохранённый в адресе закладки Safari. Для распознавания новых типов карточек нужен код из раздела «Установка» версии 3.4.
