# Проверка scanner test 3.5.4

Взяты публичные задания с двух платформ. Повторный прогон сравнивает локальный точный расчёт с независимым вычислением через Python Fraction. Остальные текстовые задания передавались функции решения опубликованного Worker с реальными облачными моделями. Авторизацию и списание лимита имитировал стенд. Эталоны Kahoot были отделены от запроса. Несколько правильных вариантов, вопросы без однозначного эталона и задания с нечитаемыми изображениями не дают оснований заявлять общую точность. Тесты на iPhone и полноценные игровые сессии не проводились.
